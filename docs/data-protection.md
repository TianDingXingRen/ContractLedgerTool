# 本地数据保护

本软件在 Windows/NTFS 上提供可选的 EFS 静态数据保护。默认保持关闭，只有用户在“诊断信息”页确认恢复风险后才会执行。

保护范围包括：

- SQLite 数据库和完整备份；
- 合同模板与上传的源 DOCX；
- 已生成的合同、采购文档和临时生成目录；
- 浏览器填写会话；
- `config.json` 与 Flask 本地密钥文件。

EFS 是 Windows 用户级透明加密。它主要防止硬盘离线读取和其他 Windows 用户访问，不防止当前已登录账户中的恶意程序。启用后，新建到受保护目录的文件会继承加密属性。

## 恢复要求

EFS 文件依赖当前 Windows 用户的证书和私钥。重装系统、删除账户或丢失私钥可能导致数据永久无法恢复。启用后应立即通过 Windows 证书管理器导出“加密文件系统”证书及私钥，并把 PFX 备份保存到离线介质。

启用过程会独占维护锁，避免数据库或文档在加密过程中继续写入。如果任一项目加密失败，程序会按逆序回滚本次已经加密的项目，并单独报告无法回滚的路径。EFS 证书是否已经离线备份仍需用户人工确认。

迁移到新电脑前，应先确认私钥备份可用；也可以在旧电脑上解密或导出完整数据包后再迁移。
