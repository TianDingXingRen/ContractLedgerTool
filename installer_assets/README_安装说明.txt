合同管理工具 - 离线安装包

适用系统：
Windows 10 / Windows 11

安装前提：
无需提前安装 Python，无需联网下载依赖。

安装方法：
1. 双击“合同管理工具_安装包.exe”。
2. 等待安装完成。
3. 安装完成后会自动启动浏览器，打开合同管理工具。
4. 安装脚本会默认启用开机自启动；如需跳过，可使用 PowerShell 运行 install.ps1 -NoAutostart。

日常使用：
桌面会生成“合同管理工具”快捷方式，以后双击它即可启动。

默认访问地址：
http://127.0.0.1:5000/

默认安装位置：
%LOCALAPPDATA%\ContractLedgerTool

数据位置：
合同台账数据库、生成的合同文件、上传模板文件都保存在默认安装目录下。

注意事项：
1. 该安装包已内置运行环境和依赖，可在离线电脑上安装。
2. 该工具默认只在本机访问，不会主动暴露到局域网。
3. 如果 5000 端口被其他软件占用，请关闭占用程序后重新启动。
